# SpectreManifest

Spectre feed metadata - depots, manifest GIDs, buildids (no decryption keys)

Public manifest metadata feed for Steam apps, generated by the Spectre toolchain.

## Layout

```
<appId>/<appId>.json
```

Each JSON describes one app: name, public/beta branch build IDs, and the depot
table — depot IDs, manifest GIDs, download sizes, OS lists, DLC app IDs and
shared-install flags.

## What is NOT included

- Decryption keys (`decryptionkey` fields are stripped from every depot entry)
- Lua plugin files and `key.vdf` artifacts
- Any account credentials, tokens or machine-local state

The feed is metadata only: branch information and manifest locations/sizes.

## Consumption

Raw URLs follow the pattern:

```
https://raw.githubusercontent.com/WallasSCRIPTS/SpectreManifest/main/<appId>/<appId>.json
```

## Freshness

Regenerated from the Spectre feed on each update run. The `updated` field at
the top of each JSON marks when that app's data was last refreshed.
